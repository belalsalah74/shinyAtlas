The account-specific roll is implemented from public reverse-engineering code and reference test vectors. Predictions still require the internal Player ID, a true encounter ID, and the correct odds.

Identifier checks matter. A Friend Code is not the internal Player ID, and an ordinary spawn key is not necessarily an encounter ID. Rows without the required IDs remain unpredicted.
